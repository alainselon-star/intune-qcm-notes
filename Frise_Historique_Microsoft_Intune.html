De Systems Management Server à Microsoft Intune

Trente ans de gestion de parc informatique chez Microsoft : d'un outil sur site pensé pour le PC de bureau à une plateforme cloud pilotée par l'IA, gérant aujourd'hui des flottes iOS, Android, macOS, Linux et Windows.

1994 — 2009

Avant le cloud

La gestion de parc reste une affaire de serveurs sur site.

1994Systems Management Server (SMS)

Premier outil Microsoft dédié à l'administration massive des postes : déploiement de logiciels, mises à jour, inventaire. C'est l'ancêtre direct de Configuration Manager (SCCM, ConfigMgr).

SMSon-premise
2007Asset Inventory Service

Distribué via le Microsoft Desktop Optimization Pack (MDOP) pour les clients Software Assurance, ce service se concentre sur l'inventaire et la compatibilité logicielle.

MDOPinventaire
2008Asset Inventory Service 2.0

Refonte complète en service hébergé dans le cloud, dans le sillage du virage cloud amorcé par Microsoft.

cloud
2009Projet « Florida »

Porté par le succès attendu de Windows 7, Microsoft annonce à la conférence MMS le System Center Online Desktop Manager : un service en ligne de gestion et de sécurité du poste de travail, avec inventaire, antivirus, configuration et assistance à distance — le prototype direct d'Intune.

System Center Online Desktop ManagerSilverlight
2010 — 2013

Naissance de Windows Intune

Le premier vrai service cloud de gestion des postes Windows.

2010System Center Online Desktop Manager devient Windows Intune

Repositionné comme alternative cloud à WSUS et à Configuration Manager, sans infrastructure sur site à déployer — pour des postes en entreprise comme en mobilité.

renommagealternative à WSUS
2011Disponibilité générale — 23 mars

Windows Intune devient disponible pour tous, avec la gestion des mises à jour et de la sécurité. Microsoft instaure le rythme de publication en « waves », deux fois par an — un cadencement qui structurera le produit pour les quinze années suivantes.

GAwaves semestrielles
2011–13La mobilité bouscule le marché

iPhone et Android imposent de nouveaux usages que l'administration historique de Microsoft ne couvre pas. Des acteurs tiers — AirWatch, MobileIron — occupent le terrain du MDM mobile.

iOSAndroidAirWatchMobileIron
2014 — 2016

Microsoft Intune et l'ère MDM

Le service quitte le seul monde Windows pour devenir multiplateforme.

2014Rebaptisé Microsoft Intune

Intégré à la suite Enterprise Mobility + Security (EMS) aux côtés d'Azure Active Directory et d'Azure Rights Management, le service prend en charge iOS, Android, macOS et Windows Phone. En parallèle, Google lance son propre framework, Android Enterprise, pour dépasser les limites du mode historique Device Administrator.

renommageEMSAzure ADAndroid Enterprise
2015Windows 10, CSP et MAM sans enregistrement

Le support d'OMA-URI et des Configuration Service Providers (CSP) remplace avantageusement les stratégies de groupe. Arrivent aussi Windows Update for Business, Windows Store for Business, le premier support de macOS — et surtout une idée neuve : un SDK intégré aux applications (dont Office) pour appliquer des stratégies de sécurité sans avoir à inscrire l'appareil. Le BYOD devient enfin gérable sans encapsulation.

CSPWindows Update for BusinessMAM sans enregistrementmacOS
2016Cadence mensuelle et accès conditionnel

Les mises à jour de service deviennent mensuelles. Les groupes Intune convergent vers ceux d'Azure AD, la restriction d'enregistrement par plateforme apparaît, et l'accès conditionnel fait son entrée dans Azure AD, s'appuyant sur la conformité Intune. Microsoft rejoint le peloton de tête des cabinets d'analystes (Gartner, Forrester, IDC).

accès conditionnelGartner
2017 — 2019

La gestion moderne

Intune apprend à cohabiter avec Configuration Manager, puis à le dépasser.

2017Cogestion et Windows Autopilot

La cogestion permet de piloter un même poste Windows avec Configuration Manager et Intune, pour une transition progressive plutôt qu'un big bang. Windows Autopilot réinvente le provisionnement : l'appareil part directement du fabricant vers l'utilisateur, sans passer par l'IT. L'Intune Management Extension (« sidecar ») ajoute l'installation d'exécutables et de scripts PowerShell, en complément des CSP.

cogestionWindows AutopilotIntune Management ExtensionRBAC
2018Microsoft Graph et l'accélération

L'API Intune s'ouvre dans Microsoft Graph, offrant un modèle de programmation unifié aux développeurs. Le service gagne près d'un million d'appareils par mois — environ 70 millions de licences EMS ont été vendues. Samsung KNOX, le mode kiosk Android (COSU) et un connecteur avec Microsoft Defender for Endpoint complètent l'offre.

Microsoft GraphKNOXDefender for Endpoint
2019Security Baselines et fin de MBAM

Microsoft rapatrie dans Intune la gestion de BitLocker (fin de support de MBAM), désormais accessible aux licences Windows Pro, et introduit les Security Baselines. Le portail est temporairement renommé « Microsoft 365 Device Management (DMAC) » le temps d'une refonte graphique et d'une nouvelle approche des rapports.

Security BaselinesBitLockerDesktop Analytics
2020 — 2021

Endpoint Manager et l'unification

Intune, Configuration Manager et Autopilot sous une même bannière — pour un temps.

2020Naissance de Microsoft Endpoint Manager

Le cap des 10 millions d'appareils Windows gérés est franchi. Microsoft unifie Intune, Configuration Manager, Windows Autopilot et le nouvel Endpoint Analytics sous le nom Microsoft Endpoint Manager. Le renommage ne prendra jamais vraiment auprès des entreprises. Cette même année arrivent Microsoft Tunnel (VPN pour iOS/Android) et le nœud Endpoint Security, guichet unique pour les paramètres de sécurité.

renommageEndpoint AnalyticsMicrosoft Tunnel
2021Settings Catalog et Windows 365

Le Settings Catalog unifie les paramètres de configuration pour toutes les plateformes. Les filtres pallient les limites d'évaluation des groupes Entra ID. Windows 365 (Cloud PC) et Remote Help — très attendu depuis le retrait du support à distance historique — complètent l'offre, aux côtés du mode Android COPE et du DFCI pour configurer le BIOS à distance. L'année se referme sur le lancement de Windows 11.

Settings CatalogWindows 365Remote HelpDFCI
2022 — 2023

Retour à Intune, et la Suite

Le nom revient, la plateforme s'élargit à Linux, macOS et aux privilèges.

2022Microsoft Endpoint Manager redevient Microsoft Intune

Retour en arrière assumé. Microsoft lance Microsoft Intune Suite en complément du Plan 1 historique — Remote Help, gestion avancée des applications, des certificats, des privilèges — ainsi que le Plan 2 pour les appareils spécialisés (casques AR/VR, écrans de salle). Le support de Linux (et WSL) et de macOS s'étoffe nettement, avec Windows Autopatch pour automatiser les mises à jour.

renommageMicrosoft Intune SuiteLinuxWindows Autopatch
2023Endpoint Privilege Management

EPM permet d'élever temporairement les privilèges d'un utilisateur standard, sans compte admin partagé. Windows LAPS rejoint Intune pour la rotation des mots de passe administrateurs locaux. Remote Help s'étend à Android et macOS, un connecteur ServiceNow apparaît, et la gestion des firmwares et pilotes Windows via Windows Update for Business voit enfin le jour.

Endpoint Privilege ManagementWindows LAPSServiceNow
2024 — 2025

L'ère de l'IA

Copilot s'invite dans la gestion des postes, PKI et analytique deviennent natifs.

2024Advanced Analytics, Cloud PKI et Security Copilot

Intune Suite s'enrichit d'Advanced Analytics (chronologie détaillée par appareil, rapport batterie), d'Enterprise Application Management (catalogue d'applications prépackagées) et de Cloud PKI, une autorité de certification entièrement cloud. Microsoft Security Copilot fait son entrée avec des scénarios dédiés à Intune : dépannage, création de stratégies, rédaction de requêtes KQL. Une nouvelle génération de Windows Autopilot, « device preparation », est annoncée.

Advanced AnalyticsCloud PKISecurity CopilotKQL
2025Device Query et gestion pilotée par l'IA

Device Query permet d'interroger les appareils en KQL en temps réel, et Security Copilot génère ces requêtes en langage naturel. EPM gagne le support ARM64, Windows 11 introduit les mises à jour à chaud sans redémarrage, et de nouveaux agents Security Copilot commencent à agir eux-mêmes face aux vulnérabilités détectées.

Device QueryARM64agents IA

Trente ans après Systems Management Server, Microsoft Intune gère aujourd'hui plus de 150 millions d'appareils dans le monde — Windows, iOS, Android, macOS et Linux confondus, avec une plateforme entièrement cloud et, désormais, assistée par l'IA.
