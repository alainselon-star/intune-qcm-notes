Labo Intune — Windows Autopilot

Mise en pratique du chapitre « Windows Autopilot » sur un tenant réel

Scénario : vous préparez le provisionnement automatique d'un poste neuf pour un utilisateur test, sans jamais toucher physiquement à un vrai PC — en import manuel du hash, exactement le chemin « toujours disponible » que la fiche de cours décrit en premier. Les exercices suivent l'ordre du chapitre : enregistrement, profil de déploiement, page d'état d'enregistrement (ESP), puis réinitialisation.

Prérequis à vérifier avant de commencer Licence Intune Plan 1 sur votre compte admin. Pour l'import réel d'un hash matériel (exercice 1), il faut soit un appareil Windows physique sur lequel exécuter un script PowerShell de collecte, soit un fichier CSV d'exemple déjà préparé — sans appareil disponible, traitez l'exercice en observation de l'écran d'import. Tenant utilisé : NextstepPRO.onmicrosoft.com (ou votre tenant de pratique).
Cours § 2 — Trois façons d'enregistrer un appareil

Exercice 1 — Importer un appareil via le chemin manuel Enregistrement

But : parcourir le chemin manuel du chapitre — celui qui ne dépend d'aucun OEM ni revendeur, disponible quelle que soit la taille de l'organisation.
  1. Sur un appareil Windows test → PowerShell en administrateurInstallez le module : Install-Script Get-WindowsAutoPilotInfo, puis exécutez Get-WindowsAutoPilotInfo.ps1 -OutputFile hash.csv.
  2. Devices → Enrollment → Windows → Windows Autopilot devices → ImportChargez le fichier hash.csv (jusqu'à 500 lignes par import).
  3. SyncCliquez sur Sync et patientez quelques minutes avant de rafraîchir la liste.
Résultat attenduL'appareil apparaît dans Windows Autopilot devices avec son numéro de série et un profil « Not assigned » — il est désormais connu de la base Autopilot, pas encore de votre tenant Entra ID.
Cours § 3 — Configurer le provisionnement historique

Exercice 2 — Créer un profil de déploiement conduit par l'utilisateur Profil

But : définir l'expérience d'accueil (OOBE) du cas standard — l'utilisateur s'authentifie lui-même.
  1. Devices → Enrollment → Windows → Deployment Profiles → Create profileType : Windows PC. Nom : DEP-UserDriven-Pilote.
  2. Out-of-box experience (OOBE)Join type : Microsoft Entra joined. Deployment mode : User-Driven.
  3. Masquage des écransActivez Hide Privacy Settings et Hide EULA — cases disponibles uniquement en mode historique, absentes de Device Preparation.
  4. AssignmentsAssignez au groupe dynamique ou statique contenant l'appareil importé à l'exercice 1.
Résultat attenduLe profil DEP-UserDriven-Pilote apparaît dans Deployment Profiles avec un statut « Assigned » sur l'appareil de l'exercice 1.
Cours § 3 — La page d'état d'enregistrement (ESP)

Exercice 3 — Créer une page ESP Blocage contrôlé

But : matérialiser le blocage volontaire de l'accès au bureau tant que les éléments requis ne sont pas installés.
  1. Devices → Enrollment → Windows → Enrollment Status Page → CreateNom : ESP-Pilote.
  2. SettingsShow app and profile configuration progress : Yes. Block device use until all apps and profiles are installed : Yes, pour la phase Device setup uniquement dans un premier temps.
  3. AssignmentsMême groupe que le profil de déploiement de l'exercice 2 — l'ESP doit toujours cibler exactement le même périmètre que les applications qu'elle attend.
Résultat attenduESP-Pilote apparaît dans Enrollment Status Page, classée par ordre de priorité par rapport à la page par défaut.

Piège classique du cours : une application ciblée par l'ESP mais jamais assignée depuis le menu Apps bloque indéfiniment la progression — vérifiez que le même groupe reçoit au moins une application si vous testez avec un vrai appareil.

Cours § 6 — Remettre un appareil en circulation

Exercice 4 — Comparer les trois niveaux de réinitialisation Lecture

But : savoir choisir le bon outil de reset selon le scénario métier — changer d'utilisateur, nettoyer, ou mettre au rebut.
  1. Devices → All devices → (un appareil géré) → Autopilot ResetSans l'exécuter si l'appareil est important : repérez le bouton et son comportement annoncé (conserve la jointure, retire le profil utilisateur).
  2. Devices → All devices → (même appareil) → Fresh StartRepérez la case à cocher qui permet de conserver les fichiers utilisateur.
  3. Devices → All devices → (même appareil) → WipeRepérez les deux cases à cocher indépendantes (conserver la jointure, conserver les données) — sans jamais cliquer sur Wipe pour un appareil réel pendant ce labo.
Résultat attenduVous savez associer chaque scénario à son outil : changer d'utilisateur → Autopilot Reset ; nettoyer sans perdre les fichiers → Fresh Start ; mettre au rebut → Wipe.

✓Nettoyage

Avant de refermer le labo, supprimez les objets créés — sinon ils polluent le tenant pour les prochaines sessions.
